# OrcheStore Community Code of Conduct

## Our Commitment

OrcheStore aims to provide an open, welcoming, and collaborative environment for everyone interested in using, discussing, or contributing to the project.

Whether you are reporting issues, suggesting features, improving documentation, contributing code, or participating in discussions, you are expected to treat others with respect and professionalism.

---

## Expected Behavior

Community members are encouraged to:

- Be respectful and constructive in discussions
- Give feedback in a helpful and professional manner
- Focus on improving the project and helping others
- Be welcoming to new contributors and users
- Assume good intentions and communicate thoughtfully
- Respect differing viewpoints and experiences

---

## Unacceptable Behavior

The following behaviors are not acceptable:

- Harassment, discrimination, or hateful conduct
- Personal attacks, insults, or hostile language
- Trolling, baiting, or intentionally disruptive behavior
- Publishing private information without permission
- Repeatedly derailing discussions or contributions
- Any conduct that creates an unwelcoming environment

---

## Scope

This Code of Conduct applies to all OrcheStore project spaces, including:

- GitHub issues
- Pull requests
- Discussions
- Documentation contributions
- Community conversations related to the project

---

## Maintainer Responsibilities

Project maintainers are responsible for maintaining a respectful and productive environment.

Maintainers may edit, remove, reject, or moderate comments, issues, pull requests, discussions, or other contributions that violate this Code of Conduct.

In cases of repeated or severe violations, maintainers may temporarily or permanently restrict participation in the project.

---

## Reporting Issues

If you experience or witness behavior that violates this Code of Conduct, please contact the maintainers through GitHub.

Reports will be reviewed fairly and handled with appropriate discretion.

---

## Our Goal

OrcheStore exists to improve the developer experience by simplifying and automating common patterns across the React, Redux, and TypeScript ecosystem.

The community should reflect the same philosophy: constructive collaboration, practical solutions, and a shared focus on helping developers build better software with less complexity.
